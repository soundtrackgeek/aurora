# Ratings 0.14.0 selected design prompt

The selected target combines the primary Taste Constellation concept with the Album Completion Studio interaction. The constellation remains the visual identity. Below it, one compact tabbed workbench provides Almost Complete, Partially Rated, and Unrated Albums, with a bounded selected-album track list and instant stars/Love.

The target also distinguishes Track Ratings from Album Ratings, keeps Album Score numeric and separate from stars, preserves Aurora's dark violet/cyan Windows 11 shell, and uses the live catalog counts documented in `ratings-studio-contract.md`.
